# CompareHome KZ

Мобильное приложение (React + Capacitor) для сравнения квартир в новостройках разных застройщиков Казахстана. Каталог с фильтрами, сравнение 2–4 квартир в одном масштабе, избранное, ипотечный калькулятор по программам Отбасы банка, профили застройщиков и карта ЖК.

## Стек

Vite 8, React 19, TypeScript, Ionic 9 (только навигация и шторки — внешний вид свой), Capacitor 8, Supabase (Postgres, только чтение через RLS), TanStack Query с кэшем на устройстве, Zustand, Leaflet + OpenStreetMap, Vitest.

## Запуск

```bash
npm install
cp .env.example .env   # URL и publishable key проекта Supabase
npm run dev            # http://localhost:5173
```

Проверки: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.

## Android

Нужен Android Studio (в нём JDK 21 и Android SDK). После установки:

```powershell
setx JAVA_HOME "C:\Program Files\Android\Android Studio\jbr"
setx ANDROID_HOME "%LOCALAPPDATA%\Android\Sdk"
```

Затем `npm run android` — соберёт веб-часть, синхронизирует её в `android/` и откроет проект в Android Studio, где можно запустить эмулятор или телефон. Иконки и заставка пересобираются командой `npm run assets` из `scripts/assets/render-icons.ts`.

iOS собирается только на macOS: `npx cap add ios`, затем Xcode.

## Данные

Всё, что видит пользователь, хранится в Supabase и собрано из открытых источников. Список источников с датами — на экране «Откуда данные».

| Что | Откуда |
|---|---|
| Квартиры: цена, площадь, комнаты, этаж | Публичные каталоги Sensata Group, BI Group, BAZIS-A (выборка, собрана вручную 17.10.2026) |
| Защита дольщиков, адрес, плановый ввод | Сводка developers.kz по реестру долевого строительства, срез 27.09.2026 |
| Средняя цена нового жилья по городам | БНС, «Цены на рынке жилья», 2025 год |
| Ипотека «Наурыз», «Отау» | hcsbk.kz |
| Координаты ЖК | OpenStreetMap / Nominatim, по улице из адреса |
| Планировки, фото, рендеры и интерьеры | Сайты застройщиков: ссылки на их изображения, собраны 23.10.2026 |

Если статус ЖК не удалось однозначно подтвердить, он помечен «Не проверено», а не «нет в реестре».

### Изображения

Приложение не хранит копий изображений. В `data/curated/media.json` записаны только ссылки на файлы застройщиков: S3 BI Group, admin.shablon.bazis.kz и bazis-online.kz, sensata.kz, Profitbase. Картинки загружаются прямо с этих адресов без заголовка Referer, а под каждой стоит подпись «Фото: застройщик» со ссылкой на страницу-источник. Если застройщик удалил файл, вместо картинки показывается надпись «Изображение недоступно», а обложка ЖК скрывается целиком. Схема «Единого масштаба» от этого не зависит.

Права на изображения принадлежат застройщикам. Для демо и учебного проекта показа по ссылке с указанием источника достаточно. **Для публикации в Google Play нужно письменное согласие каждого застройщика** или собственные фото и рендеры.

Планировки застройщиков нарисованы в разном масштабе, поэтому в приложении они дополняют контур, а не заменяют его. В сравнении планировки раскрываются по кнопке, чтобы зря не грузить мегабайты: у Sensata один файл весит около 1,4 МБ.

### Как обновить данные

1. Поправьте файлы в `data/curated/` (квартиры — `apartments.json`, ЖК — `complexes.json`, изображения — `media.json` и т. д.).
2. Для новых ЖК с адресом: `npm run data:geocode` — проставит координаты.
3. `npm run data:seed` — проверит данные и соберёт `supabase/seed.sql`. Если планировка в `media.json` ссылается на квартиру, которой нет в выборке (пара `complex_id` + `unit_no`), сборка остановится с ошибкой.
4. Выполните `supabase/seed.sql` в SQL Editor панели Supabase. Скрипт идемпотентный: обновляет существующие строки, а квартиры и изображения, которых больше нет в файлах, удаляет.

Если квартира ушла из продажи, застройщик обычно убирает и её планировку. Поэтому при обновлении выборки квартир заново соберите для неё ссылки на планировки.

Схема БД — в `supabase/migrations/`.

## Структура

```
src/domain/      логика без UI: сравнение, ипотека, фильтры, контуры (покрыта тестами)
src/data/        Supabase, запросы, маппинг строк
src/store/       сравнение, избранное, фильтры (сохраняются на устройстве)
src/components/  контур квартиры, маркер, строки списков, шторки, изображения и просмотр с зумом
src/pages/       экраны
src/theme/       токены «Единого масштаба»: калька, графит, бирюза, маркер
scripts/         импорт данных и генерация иконок
```
